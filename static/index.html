Tip: Para mejores resultados con el OCR clásico, asegúrate de que la placa esté bien iluminada y el vehículo no esté en movimiento rápido. El sistema detecta placas colombianas en los formatos ABC-123 y AB-1234.

Acerca del Proyecto

ForenSys Vision V2 — Sistema de Inteligencia Forense Digital

ForenSys Vision V2 es un sistema de inteligencia forense digital desarrollado como proyecto de grado. Integra reconocimiento facial y de placas en tiempo real, trazado de rutas geoespaciales, generación de reportes periciales y geolocalización persistente del dispositivo.

Tecnologías V2

  • Python 3 + FastAPI
  • OpenCV + YuNet + LBPH
  • EasyOCR (placas)
  • Leaflet.js + OpenStreetMap
  • SQLAlchemy + SQLite
  • HTML5 / CSS3 / JavaScript

Módulos V2

  • Reconocimiento facial en vivo
  • Reconocimiento de placas CO
  • Trazador de rutas forense
  • Generador de reportes periciales
  • Geolocalización persistente
  • Gestión CRUD de sospechosos
