Acerca del Proyecto

ForenSys Vision V1 — Sistema de Inteligencia Forense Digital

ForenSys Vision V1 es un sistema de inteligencia forense digital desarrollado como proyecto de grado. Integra reconocimiento facial en tiempo real mediante OpenCV LBPH, un motor de predicción estadística de conductas delictivas, gestión de base de datos de sospechosos y monitoreo biométrico en vivo.
